# Asia Motor — демо редизайна

Концепция нового сайта для магазина автозапчастей [Asia Motor](https://asiamotor.com.ua/) (Запорожье, запчасти для китайских автомобилей).
Это **демонстрационная версия** для презентации владельцу: интерфейс полностью рабочий, но каталог, заказ и оплата к реальной базе магазина не подключены.

## Запуск

Нужен Node.js 20+.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:5173. Продакшен-сборка и локальный просмотр:

```bash
npm run build
```

```bash
npm run preview
```

Готовая статика лежит в `dist/`. Пути к ресурсам относительные (`base: './'`), поэтому сборку можно выложить и в корень домена, и в подпапку: Netlify, Vercel, GitHub Pages, обычный веб-сервер.

### Публичная демо-ссылка (GitHub Pages)

Собранный сайт лежит в папке `docs/` — GitHub Pages публикует её напрямую, без сборки. Включается один раз:
**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/docs` → Save.**
Адрес: https://k1s1l.github.io/AsiaMotor/

После изменений в коде обновите папку `docs/`:

```bash
npm run build && rm -rf docs && cp -r dist docs && touch docs/.nojekyll
```

## Стек и библиотеки

- **React 19 + TypeScript + Vite** — приложение
- **Tailwind CSS 4** — стили и дизайн-токены (`src/index.css`, блок `@theme`)
- **three.js** — 3D-сцена первого экрана (загружается отдельным чанком)
- **GSAP + ScrollTrigger** — таймлайн сборки, reveal-анимации, pin-секция
- **Lenis** — плавная прокрутка (отключается при reduced motion)
- **lucide-react** — иконки
- **Fontsource**: Unbounded (заголовки), Manrope (текст), JetBrains Mono (артикулы, подписи) — все с кириллицей, грузятся локально
- **Playwright + ffmpeg** — только для офлайн-рендера картинок категорий в `tools/`

## Демонстрационные данные и неподключённые интеграции

**Реальные данные (с asiamotor.com.ua и справочников, которые их повторяют):** год начала работы (2005), город и адрес (Запорожье, ул. Кривая Бухта, 2), телефоны 050 641 04 10 и 097 412 29 25, e-mail info@asiamotor.com.ua, марки (Chery, Geely, Great Wall, Haval, BYD, Lifan), доставка «Нова пошта» / Delivery, заказ из Китая (авиа ≈ 2 недели, море — до 3 месяцев), склад, опт и розница, названия, артикулы и цены 9 товаров витрины.

**Нужно сверить с владельцем перед запуском:**
- Цены товаров взяты с публичных страниц магазина на момент подготовки демо и могли измениться. Наличие неизвестно — везде указано «Наличие уточняйте».
- График работы в разных справочниках расходится, поэтому на сайте его нет («уточняйте по телефону»).
- Способы оплаты не подтверждены — в панели «Доставка и оплата» стоит «уточняйте у менеджера».
- В секции «Марки» под названием марки показаны только модели, которые встречаются в названиях товаров магазина; полный список стоит взять из каталога.

**Демо (не подключено):**
- Справочник «марка → модель → год → двигатель» (`data/vehicles.ts`) — пример. Подбор ищет только среди 9 товаров витрины.
- Поиск работает по 9 демо-товарам.
- Корзина хранится в `localStorage` браузера; оформление заказа и оплата не реализованы.
- «Подбор по VIN» открывает письмо на info@asiamotor.com.ua (mailto), без серверной формы.
- Логотип — временный текстовый знак, а не официальный логотип Asia Motor.

**Точки интеграции для боевой версии:** заменить `data/products.ts` и `data/vehicles.ts` на запросы к API каталога, `matchProducts()` в `store.tsx` — на серверный поиск, кнопку «Оформить заказ» в `Overlays.tsx` — на форму заказа / CRM.

## 3D-сборка на первом экране

Код: `src/three/assembly.ts` (сцена) и `src/components/Hero.tsx` (загрузка, интерфейс, режимы).

**Модель.** Открытой модели Haval H6 с разрешённой лицензией нет: такие модели продаются на 3D-маркетплейсах, а дизайн и марка принадлежат производителю. Поэтому в демо — **«Car Concept»** из официальной коллекции Khronos glTF (Eric Chadwick, Darmstadt Graphics Group, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); основа — public domain модель Unity Fan). Изменены цвет, материалы, номерной знак; модель оптимизирована с 11,7 до 2,5 МБ. Атрибуция стоит в футере — по лицензии её нельзя убирать.

**Как поставить другую модель (например, купленную Haval H6):**
1. Экспортируйте её в GLB, детали — отдельными узлами с понятными именами (двери, капот, колёса, фары и т. д.).
2. Оптимизируйте, например: `npx @gltf-transform/cli optimize in.glb public/models/car.glb --compress meshopt --texture-compress webp --texture-size 1024`.
3. В `STAGES` в `src/three/assembly.ts` поменяйте регулярные выражения под имена узлов новой модели. Ориентацию (ось вверх и направление фар) сцена определяет сама.
4. Перерендерите статичные кадры `media/car-hero*.webp`.

**Режимы:**
- первый визит во вкладке — полная сборка (~11 с на компьютере, ~8 с на телефоне), «Пропустить» сразу переводит к финалу;
- повторные визиты в той же вкладке — сразу собранная машина и кнопка «Собрать ещё раз»;
- телефоны — без bloom, меньше разрешение рендера и теней, короче таймлайн;
- нет WebGL2, программный рендеринг, экономия трафика, ≤ 2 ГБ памяти или ≤ 2 ядра, `prefers-reduced-motion` — статичная картинка, модель не скачивается;
- для показа: `?3d=force` — всегда 3D, `?3d=static` — всегда картинка.

Рендер ставится на паузу, когда первый экран прокручен или вкладка скрыта; шейдеры компилируются во время загрузки, чтобы сборка не подтормаживала.

## Медиа: что это и как заменить

Из среды разработки не было доступа к фото- и видеостокам, поэтому все визуальные материалы — **собственный CGI**: процедурные 3D-модели деталей (тормозной диск с суппортом, шестерни, амортизатор с пружиной, поршень с шатуном, генератор, фара, вентилятор с радиатором, руль и т. д.), отрендеренные в three.js. Лицензионных ограничений нет. Изображения в карточках товаров — иллюстрации категории и помечены «Иллюстрация».

Чтобы поставить финальные материалы, достаточно положить файлы с теми же именами в `public/media/`:

| Файл | Где используется | Рекомендации |
| --- | --- | --- |
| `car-hero.webp`, `car-hero-mobile.webp` | Статичный первый экран (нет WebGL, слабое устройство, экономия трафика, `prefers-reduced-motion`) | кадр собранного авто, 1920×1080 и 720×1280 |
| `cat-*.webp` | Карточки категорий (10 шт.) | 1600×1200, объект по центру |
| `story-macro.webp` | Секция «Философия» | 2400×1200, объект справа |
| `p-*.webp` / поле `image` в `data/products.ts` | Фото товаров | квадрат 1200×1200, светлый фон |

Чтобы перерендерить CGI (например, после правок моделей в `tools/studio/parts.ts`), нужны Playwright и ffmpeg:

```bash
node tools/render.mjs all
```

Варианты: `stills` (только картинки), `cat-brakes,p-hood` (отдельные кадры), флаг `--preview` — быстрый черновик в половинном разрешении.

## Доступность и производительность

- Семантическая разметка, `aria`-подписи у иконок, видимый фокус, Esc закрывает панели, фокус переносится в открытую панель.
- `prefers-reduced-motion`: вместо 3D-сборки — статичный кадр, без плавного скролла и scroll-анимаций.
- Изображения ниже первого экрана — `loading="lazy"`; three.js и модель грузятся только там, где будет 3D.
- Шрифты локальные; общий вес JS ≈ 143 КБ gzip.
