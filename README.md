# Asia Motor — интернет-магазин

Новый сайт магазина автозапчастей [Asia Motor](https://asiamotor.com.ua/) (Запорожье, запчасти для китайских автомобилей): 3D-главная, каталог из 2 639 реальных товаров из прайса магазина, страницы товаров, «Моё авто», корзина, оформление заказа и формы заявок с отправкой писем на почту магазина, SEO-страницы моделей.

Как запустить на хостинге, подключить почту и обновлять каталог — [`spec/07-launch.md`](spec/07-launch.md).

## Запуск

Нужен Node.js 20+.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:5173.

| Команда | Что делает |
|---|---|
| `npm run build` | production-сборка в `dist/` (для корня домена) |
| `npm run build:pages` | сборка для GitHub Pages (`/AsiaMotor/`) + статические HTML всех страниц, `sitemap.xml`, `robots.txt` |
| `npm run deploy:docs` | `build:pages` и копирование результата в `docs/` (папку публикует GitHub Pages) |
| `npm run catalog:import -- прайс.xls` | обновить каталог из прайса 1С (см. `spec/07-launch.md`) |
| `npm run test:pricing` | тесты движка ценообразования |
| `npm run model:inspect` | какие узлы 3D-модели попадают в какой этап сборки |
| `npm run model:optimize -- in.glb out.glb` | оптимизация новой модели для сайта |
| `npm run render` | перерендер 3D-иллюстраций деталей (нужны Playwright и ffmpeg) |

Публикация: **Settings → Pages → Deploy from a branch → `main` / `/docs`**. Адрес: https://k1s1l.github.io/AsiaMotor/

Для своего домена: `BASE_PATH=/ npm run build && BASE_PATH=/ npx tsx scripts/prerender.ts`, затем поменяйте `ORIGIN` в `src/lib/seo.ts`.

## Данные

- **Каталог** — прайс магазина (выгрузка 1С от 30.10.2026): названия, артикулы, коды, розничные цены, остатки, совместимость по группам «марка → модель». Разделы присвоены по названию (`scripts/catalog-rules.ts`). Оптовые цены и реквизиты из прайса не публикуются.
- **Фото товаров** в прайсе нет: у товаров заглушка «Фото — по запросу». Как добавить фото — `spec/07-launch.md`.
- **Описаний, производителя, годов выпуска** в прайсе нет — на сайте они не показываются.
- **Контакты, доставка, оплата** — из шапки прайса и с asiamotor.com.ua.
- **Иллюстрации разделов** на плитках категорий — 3D-рендеры типов деталей (не фото товаров).
- **Формы** работают на хостинге с функциями (Cloudflare Pages) после настройки почты. На GitHub Pages сервера нет — формы показывают ошибку и телефон магазина.
- **Модуль конкурентного ценообразования** (`src/pricing/engine.ts`, тесты, `spec/03-pricing.md`) оставлен в коде для будущей админки; на сайте его нет.

## Стек

React 19, TypeScript, Vite, React Router, Tailwind CSS 4, GSAP + ScrollTrigger, Lenis, three.js (3D-главная, отдельный чанк), lucide-react, шрифты Unbounded / Manrope / JetBrains Mono (локально). Тесты движка цен — `node:test` через tsx.

## 3D-модель

«Car Concept» из Khronos glTF Sample Assets — Eric Chadwick, Darmstadt Graphics Group, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) (основа — public domain модель Unity Fan); изменены окраска, материалы, номерной знак, модель оптимизирована. Атрибуция в футере обязательна. Это не китайский кроссовер: свободно лицензированной реалистичной модели кроссовера с разделёнными деталями нет. Модель описана в `src/three/models.ts`, купленную модель (рекомендуем Haval H6) можно подставить без изменения кода — пошагово в [`spec/06-3d-model.md`](spec/06-3d-model.md).
