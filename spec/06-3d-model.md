# 3D-модель для главной: выбор, лицензия, замена

## Что сейчас на сайте и почему

Анимация на главной идёт в реальном времени в браузере на three.js, без видео и без статичных картинок:

1. включается тёмная студия;
2. в центре проявляется голограмма автомобиля;
3. машина разбирается на узлы;
4. узлы по очереди встают на место: шасси → подвеска и тормоза → двигатель → салон → кузов → двери и капот → колёса → оптика;
5. включаются фары, камера подлетает и облетает машину;
6. после этого появляются логотип, заголовок и кнопка «Перейти в каталог».

**Модель.** Сейчас используется «Car Concept» из официальной коллекции Khronos glTF Sample Assets. Авторы — Eric Chadwick и Darmstadt Graphics Group, лицензия CC BY 4.0, атрибуция стоит в футере.

Мы искали модель современного китайского кроссовера (Haval, Geely, Chery, BYD), которая отвечала бы трём условиям сразу. Искали в открытых коллекциях (Khronos, npm, Poly Haven, бесплатные модели с лицензией CC0/CC BY). Подходящей не нашлось. Условия такие:

- **лицензия разрешает коммерческое использование на сайте;**
- **модель реалистичная**, без мультяшного стиля;
- **детали разделены и подписаны:** двери, капот, колёса, оптика, салон.

Бесплатные модели кроссоверов обычно не проходят хотя бы по одному пункту:

- у них нет лицензии или запрещено коммерческое использование;
- кузов сделан одним цельным мешем;
- это фан-модели, у которых неясно, кто владелец прав.

«Car Concept» — единственная найденная реалистичная модель, у которой есть всё сразу: свободная лицензия, PBR-материалы (лак с clearcoat, стекло, хром) и поименованные узлы. Поэтому её взяли как временную. Код от неё не зависит.

## Рекомендация: купить модель кроссовера

**Лучший вариант — Haval H6 3-го поколения.** Это самая массовая модель из ассортимента магазина, и для неё есть отдельная страница `/cars/haval/h6`.

**Где искать:** Hum3D, CGTrader, TurboSquid, Sketchfab Store. Ориентир по цене — от $50 до $300, в зависимости от детализации и лицензии.

### Что проверить перед покупкой

- [ ] **Лицензия** — Royalty Free / Standard. Она должна разрешать использование в коммерческом проекте, в том числе в реальном времени на сайте. Не подойдут лицензии «Editorial only» и «Personal / Non-commercial».
- [ ] **Передача модели в браузер.** Лицензия должна разрешать публиковать модель в составе сайта: файл GLB скачивается браузером. Некоторые магазины требуют отдельную лицензию «for real-time / web / games» — проверьте пункт про «distribution in applications».
- [ ] **Логотипы и товарные знаки.** Права на модель не дают прав на логотип Haval. На сайте магазина запчастей это допустимо как указание на совместимость, но эмблемы лучше скрыть. Для этого есть параметр `hide` в конфиге.
- [ ] **Разделённые части:** двери (левая и правая отдельно), капот, крышка багажника, бамперы, колёса (каждое отдельно, с тормозными дисками), фары, фонари, салон, днище. В описании это обычно называется «separated parts», «opening doors» или «rigged».
- [ ] **Формат:** GLB/glTF или FBX — его можно перевести в GLB через Blender. Нужны PBR-материалы.
- [ ] **Полигонаж:** «mid-poly» до ~300 тыс. треугольников. High-poly модели на 1–3 млн треугольников нужно упрощать.
- [ ] **Двигатель и подвеска.** Для полноценного этапа «Двигатель» нужна модель с моторным отсеком; таких меньше и они дороже. В текущей модели двигатель упрощённый, поэтому на этом этапе почти ничего не видно.

## Как заменить модель

1. **Подготовить модель в Blender.** Назовите узлы понятно, например:
   - `Body`, `Hood`, `DoorFL`, `DoorFR`, `DoorRL`, `DoorRR`, `Tailgate`;
   - `BumperFront`, `BumperRear`;
   - `WheelFL` (с вложенными `BrakeFL`), …;
   - `HeadlightL`, `HeadlightR`, `TaillightL`, …;
   - `Interior…`, `Chassis`, `Suspension…`, `Engine`.

   Экспортируйте в GLB (+Y up). Масштаб и разворот не важны: сцена сама ставит машину носом вперёд и приводит её к длине `length`.
2. **Оптимизировать:**

   ```bash
   npm run model:optimize -- ~/Downloads/haval-h6.glb public/models/haval-h6.glb
   ```

   Скрипт объединяет дубликаты, удаляет лишнее, упрощает плотные меши, переводит текстуры в WebP 1024 px и сжимает геометрию (meshopt). Имена узлов сохраняются. Цель — 2–4 МБ.
3. **Описать модель** в `src/three/models.ts`. Скопируйте `carConcept` и укажите:
   - `url`, `credit`, `length` (для H6 — 4.65);
   - `frontNode` (любой узел в передней части);
   - в `stages` — регулярные выражения под новые имена; бамперы можно сделать отдельным этапом;
   - `paint` — имена материалов и их цвет;
   - `lamps` — материалы фар и фонарей с их яркостью;
   - `headlights`.

   Затем `export const MODEL = havalH6`.
4. **Проверить разбиение:**

   ```bash
   npm run model:inspect -- public/models/haval-h6.glb
   ```

   Скрипт показывает, какие узлы попали в какой этап и что не попало никуда. Непопавшее едет вместе с этапом `restStage`.
5. **Обновить атрибуцию** в футере (`src/components/Footer.tsx`), если лицензия её требует. Для купленных моделей обычно не требует.
6. **Перерендерить** статичный кадр-заглушку `public/media/car-hero(-mobile).webp`. Он показывается на слабых устройствах и при «уменьшении движения». Откройте `/?3d=force` и сделайте снимок после финала.

## Производительность

| Режим | Когда | Что |
|---|---|---|
| high | настольные компьютеры с нормальной видеокартой | сглаживание MSAA, свечение (bloom), тени 2048 |
| low | телефоны и планшеты | без bloom, тени 1024, pixel ratio ≤ 1.5, сценарий на 28 % короче |
| static | нет WebGL2, программный рендер, ≤ 2 ГБ памяти или ≤ 2 ядер, режим экономии трафика, «уменьшение движения», модель не загрузилась за 25 с | статичный рендер машины; three.js и модель не загружаются |

**Загрузка.** three.js — отдельный чанк, модель весит 2.4 МБ. Пока они грузятся, показывается экран загрузки с прогрессом. Шейдеры компилируются до старта, поэтому первые кадры не дёргаются.

**Повторный показ.** Сборка показывается один раз за сессию. При повторном заходе сразу видна готовая машина и кнопка «Собрать ещё раз». Кнопки «Пропустить» и «В каталог» доступны с первой секунды.

**Отладка:**

- `?3d=force` — 3D даже на слабом устройстве;
- `?3d=static` — заглушка;
- при параметре `3d` в консоли доступны `window.__assembly.seek(t)` и `window.__gsap`.
