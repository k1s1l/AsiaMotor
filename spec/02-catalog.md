## Модель товара

```ts
Product {
  id, slug                      // slug = ЧПУ товара: /product/krylo-perednie-live-haval-h6-…
  name: { ua, ru }
  article                       // артикул производителя (основной ключ сопоставления)
  oem?: string[]                // OEM-номера / кросс-номера (для поиска и сопоставления с конкурентами)
  manufacturer, quality         // 'original' | 'aftermarket'
  cat, sub                      // место в дереве
  price, currency, oldPrice?    // oldPrice — только если скидка реальная
  stock: 'in' | 'low' | 'order' | 'ask', lead?: [дни от, до]
  compat: Compat[]              // структурированная применяемость
  images[], specs[], description
  popularity, added             // для сортировок
}

Compat { make, model, years?: [от, до], engines?: string[] }
```

### Совместимость — главное для покупателя

- Применяемость хранится **структурно** (марка → модель → годы → двигатель), а не текстом в названии.
- Если источник не указывает годы или двигатель, сайт честно пишет «не указано» и отвечает «Модель совпадает, проверьте по VIN», а не «подходит».
- Функция `fit(product, car)` возвращает `yes | maybe | no`; на ней построены фильтр каталога, бейджи в карточках и блок проверки на странице товара.
- В рабочей версии применяемость приходит из каталога поставщика или TecDoc-подобной базы, а VIN-подбор — через сервис декодирования VIN этой же базы.

## «Моё авто»

Выбранный автомобиль хранится в браузере покупателя, показывается в шапке и автоматически фильтрует каталог, поиск и подборки на главной. Сбрасывается одним нажатием.

## Каталог: что реализовано

- Боковая панель: дерево категорий со счётчиками, авто (марка/модель/год/двигатель), цена от–до, тип детали (оригинал/аналог), «только в наличии», производитель.
- Поиск по названию, артикулу и модели (UA/RU, игнорирует пробелы и дефисы).
- Сортировка: популярные, дешевле, дороже, новинки. 24/48/96 на странице, плитка/список, «Показать ещё» + номера страниц.
- Все параметры в адресе страницы (`?q=…&sort=…&maker=…`), ссылкой можно поделиться.
- На телефоне фильтры открываются выдвижной панелью с кнопкой «Показать N».

## Демо-данные

9 реальных позиций с asiamotor.com.ua + 274 сгенерированные демо-позиции (`src/data/catalog.ts`). Демо-позиции имеют артикулы `DEMO-…`, условные цены и наличие и помечены «Демо» на карточке, странице товара и в корзине. Для них не выводится микроразметка Offer (это не реальные предложения).
