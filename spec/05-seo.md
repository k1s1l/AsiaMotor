# 05. SEO и привлечение покупателей

Цель — чтобы страницы Asia Motor находились по коммерческим запросам вроде «крило Haval H6 купити», «запчастини Haval H6», «передній бампер Haval Jolion ціна». Позиции в Google зависят от многих факторов: качество и полезность страниц, ассортимент, скорость, авторитетность сайта, конкуренция, поведение пользователей. Цена помогает конверсии, но сама по себе первое место не гарантирует. Ниже — что сделано в демо и что нужно для рабочего сайта.

## Структура и ЧПУ

| Тип страницы | Адрес | Под какой запрос |
|---|---|---|
| Раздел | `/catalog/kuzov` | «кузовні деталі для китайських авто» |
| Подраздел | `/catalog/kuzov/krylya` | «крила для китайських авто» |
| Марка | `/cars/haval` | «запчастини Haval» |
| Модель | `/cars/haval/h6` | «запчастини Haval H6», «Haval H6 запчастини ціна» |
| Товар | `/product/krylo-perednie-live-haval-h6-2014-2019-…` | «крило переднє ліве Haval H6 купити», артикул |
| Модель × раздел (следующий этап) | `/cars/haval/h6/kuzov` | «кузов Haval H6» — только при ≥ 10 товаров и уникальном тексте |

Не создаём тысячи комбинаций «модель × подраздел × год» с шаблонным текстом: такие страницы Google считает малополезными, и они тянут вниз весь сайт. Комбинации фильтров (`?maker=…&sort=…`) — `noindex` / canonical на основную страницу.

## Шаблоны Title и Description (реализованы)

- Товар: `{Название} — купити, ціна | Asia Motor`; description: название, артикул, совместимость, доставка.
- Подраздел/раздел: `{Название} [для {авто}] — купити в Україні | Asia Motor`; description с количеством позиций и марками.
- Модель: `Запчастини для {Марка Модель} — купити в Україні, ціни | Asia Motor`.

## Микроразметка Schema.org (реализована)

- `Product` на странице товара (название, артикул/sku/mpn, бренд, категория, изображение). `Offer` с ценой и наличием — **только для реальных товаров**; для демо-позиций не выводится, чтобы не публиковать условные цены.
- `BreadcrumbList` на разделах и товарах.
- `AutoPartsStore` (организация: адрес, телефоны, e-mail, год основания) на главной и в контактах.
- Отзывы и рейтинги (`AggregateRating`) не размечаются, пока нет настоящих отзывов.

## Индексация

- `sitemap.xml` генерируется при сборке (`scripts/prerender.mjs`): главная, разделы, подразделы, марки, модели, товары, информационные страницы.
- `robots.txt`: открыт каталог; закрыты `/cart`, `/checkout`, `/admin/`.
- Для каждой страницы при сборке создаётся HTML с правильными `<title>`, description, canonical, Open Graph и JSON-LD — поисковик видит их без выполнения JavaScript. В рабочей версии это заменит SSR Next.js (полный HTML с товарами).
- Языки: сейчас UA/RU переключаются на одном адресе. Для рабочего сайта — отдельные адреса (`/ru/...`) и `hreflang uk / ru`, иначе русская версия не индексируется отдельно.

## Скорость и мобильность

- 3D-сцена и модель грузятся только на главной и только на устройствах, которые её потянут; каталог и товары её не загружают.
- Изображения в WebP, `loading="lazy"`, шрифты локальные.
- В рабочей версии: AVIF/WebP разных размеров (`srcset`), CDN, SSR, Core Web Vitals в Search Console (LCP < 2,5 с, INP < 200 мс, CLS < 0,1).

## Стратегия продвижения

1. **Ассортимент и данные** — самый сильный фактор: полный каталог с артикулами, OEM-номерами, применяемостью и фото. Страницы под реальные артикулы ловят точные запросы покупателей, которые уже знают номер детали.
2. **Google Merchant Center** — бесплатные товарные объявления в Google Покупках; нужен фид с ценой и наличием (генерируется из базы).
3. **Google Business Profile** для склада в Запорожье — локальная выдача и карты.
4. **Полезный контент без воды:** короткие руководства (выбор колодок для Tiggo 7, интервалы ТО Haval H6, как найти номер детали по VIN) со ссылками на товары.
5. **Миграция без потерь:** при переезде с текущего asiamotor.com.ua — 301-редиректы со всех старых адресов товаров и разделов на новые, перенос в Search Console.
6. **Ссылки и упоминания:** профильные форумы и клубы владельцев китайских авто, каталоги автозапчастей, маркетплейсы.
7. **Аналитика:** GA4 с событиями электронной торговли, Search Console, ежемесячный отчёт по запросам и страницам.
8. **Реклама на старте:** Google Ads (поиск и Performance Max по фиду) — пока органика набирает позиции.
