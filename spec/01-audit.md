# 01. Аудит удобства покупки и план изменений

Аудит текущей версии (ветка `main` после PR #1: 3D-сборка на первом экране). Оценка — с позиции покупателя, который пришёл за конкретной деталью.

## Что работает хорошо

- Сильный визуальный образ: тёмная «автомобильная» эстетика, 3D-сборка, единый стиль CGI-иллюстраций.
- Реальные контакты, адрес, год основания, марки — всё подтверждено, ничего не выдумано.
- Подбор по авто, поиск, корзина и UA/RU уже работают.
- Хорошая производительность: 3D грузится отдельным чанком, слабые устройства получают статичный кадр.

## Главные проблемы

| # | Проблема | Почему мешает покупке | Решение |
|---|---|---|---|
| 1 | Первый экран 11 с занят сборкой, шапка скрыта, текст и кнопки появляются только в финале | Покупатель не видит поиск, каталог, корзину и телефон; кто пришёл за деталью — ждёт | Шапка (поиск, каталог, телефон, корзина) видна всегда; кнопки «Перейти в каталог» и «Пропустить» доступны с первой секунды; повторно сборка не запускается |
| 2 | Нет отдельной страницы каталога: витрина из 9 товаров на главной | Нельзя просматривать ассортимент по разделам, сортировать, листать | Страница `/catalog` с деревом категорий, фильтрами, сортировкой, пагинацией, видами «плитка / список» |
| 3 | Нет страниц товаров (карточка открывается в боковой панели) | Нельзя поделиться ссылкой, нет полной информации, страница не индексируется Google | Отдельная страница `/product/<slug>`: галерея, цена, наличие, совместимость, характеристики, доставка, похожие |
| 4 | Совместимость — только «модели из названия товара» | Покупатель не уверен, подойдёт ли деталь | Структурированная совместимость: марка → модель → годы → двигатель; блок «Подходит / не подходит к вашему авто» |
| 5 | Выбранный автомобиль не запоминается | При каждом переходе нужно выбирать заново | «Мой автомобиль» (гараж): сохраняется в браузере, показывается в шапке, фильтрует каталог |
| 6 | Нет оформления заказа | Корзина заканчивается тупиком | Страница корзины и пошаговое оформление: контакты → доставка (Нова пошта / самовывоз) → оплата → подтверждение. В демо заказ не отправляется, это прямо сказано |
| 7 | Наличие не показывается | Покупатель не понимает, ждать ли поставки | Статусы: «В наличии», «Мало», «Под заказ (срок)», «Уточняйте». Для реальных товаров без данных — «Уточняйте» |
| 8 | Нет блоков «Популярное / Новинки / Предложения / Недавно просмотренные» | Меньше поводов продолжить покупки | Добавить на главную и страницу товара |
| 9 | Декоративные элементы мешают чтению | Мелкий моноширинный текст 10–11 px, текст белым на 45 % прозрачности, закреплённая секция «Философия» (прокрутка на 160 % экрана), бегущая строка | Убрать закреплённую секцию и бегущую строку; основной текст ≥ 15 px, контраст ≥ 4.5:1; моноширинный шрифт — только для артикулов |
| 10 | Нумерация разделов «01 — Подбор» | Декор без смысла, отвлекает | Заменить простыми заголовками |
| 11 | Нет блока «Как купить» и условий в одном месте | Сомнения: как оплатить, когда приедет | Блок «Как заказать» (3 шага) + страница «Доставка и оплата» с подтверждёнными фактами |
| 12 | SEO: одна страница, один title, нет sitemap и микроразметки | Товары не находятся по запросам «крыло Haval H6 купить» | Отдельные URL, уникальные title/description, Schema.org Product, sitemap.xml, robots.txt, страницы «Запчасти для Haval H6» (см. `05-seo.md`) |

## Новая структура сайта

```
/                         Главная: hero (3D) + подбор + категории + популярное + предложения + новинки + доверие
/catalog                  Весь каталог
/catalog/<категория>      Раздел, напр. /catalog/kuzov
/catalog/<кат>/<подкат>   Подраздел, напр. /catalog/kuzov/krylya
/product/<slug>           Товар, напр. /product/krylo-perednie-live-haval-h6-2021-…
/cars/<марка>/<модель>    Запчасти для модели, напр. /cars/haval/h6
/cart                     Корзина
/checkout                 Оформление (демо)
/delivery                 Доставка, оплата, возврат
/contacts                 Контакты
/admin/pricing            Концепт панели цен (закрыт от индексации)
```

## Принципы интерфейса

1. **Цена и кнопка «В корзину» — самые контрастные элементы карточки.** Оранжевый цвет бренда — только для действий и скидок.
2. **Наличие рядом с ценой**, цветом и словом, не только цветом.
3. **«Мой автомобиль» — сквозной контекст**: шапка, каталог, страница товара.
4. **Анимации подсказывают, а не задерживают**: появление карточек ≤ 400 мс, полёт товара в корзину, плавное открытие фильтров. Ничего не блокирует прокрутку.
5. **Честность данных**: реальные товары помечены источником, демонстрационные — значком «Демо»; скидки показываются только там, где есть старая цена.

## Что остаётся демонстрационным

Пока магазин не подключён к реальной базе: демо-товары и их цены, наличие, отправка заказа, онлайн-оплата, подбор по VIN, данные конкурентов в панели цен. Как это подключить — в `04-architecture.md`.
